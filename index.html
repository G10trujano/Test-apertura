Paso 01 / 03
Product Requirement Definition
Describe la funcionalidad en lenguaje libre. El agente genera el PRD completo con modelo de datos, RFs, NFRs y criterios de aceptación.
⚡Puede ser un brief, bullets o párrafo. Incluye usuarios, sistemas y cualquier restricción regulatoria conocida.
Paso 02 / 03
User Stories
El agente extrae épicas y genera todas las historias con criterios de aceptación en Gherkin, listas para Jira o Linear.
⚡Se genera desde el PRD del paso anterior. Cada HU incluye mínimo 3 CAs: happy path, edge case y error.
Completo
Resumido
Paso 03 / 03
Prompt para Figma Make
El agente traduce las user stories en un prompt estructurado para Figma Make o Claude Code con MCP de Figma, usando los componentes reales del DS.
⚡Copia el prompt y pégalo en Claude Code + link de tu archivo Figma. Con el MCP activo escribe directo al canvas.
